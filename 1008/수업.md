## 1. 스택: 나중에 넣은 값을 먼저 꺼내기

**스택(stack)**은 LIFO(Last In, First Out) 방식으로 값을 보관한다. 32비트 모드에서 `ESP`는 스택 맨 위를 가리킨다.

- `PUSH eax`: `ESP`를 **4 줄인 뒤** EAX 값을 스택에 저장한다.
- `POP ebx`: 스택 맨 위 값을 EBX로 가져온 뒤 `ESP`를 **4 늘린다**.
- `push eax` 다음 `push ebx`를 했다면, 꺼낼 때는 `pop ebx` 다음 `pop eax` 순서여야 원래 값이 돌아온다.
- 스택은 **레지스터 임시 보관, 프로시저의 복귀 주소, 인수, 지역 변수** 등에 쓰인다. `PUSHFD`/`POPFD`는 EFLAGS를 저장/복구한다.

## 2. 프로시저와 CALL·RET

프로시저는 여러 곳에서 호출할 수 있는 코드 묶음이다. **`CALL`은 다음 명령의 주소를 스택에 저장하고 프로시저로 이동**하며, **`RET`는 저장된 주소를 꺼내 호출한 곳으로 돌아온다.** 여러 프로시저가 중첩되어도 스택에 쌓인 복귀 주소를 역순으로 꺼낸다.

```asm
SumOf PROC
    add eax, ebx
    add eax, ecx
    ret
SumOf ENDP

mov eax, 1
mov ebx, 2
mov ecx, 3
call SumOf           ; 돌아오면 EAX = 6
```

이 예시는 EAX·EBX·ECX로 값을 전달하고 EAX로 결과를 돌려준다. 프로시저 주석에는 **입력 레지스터와 반환 레지스터**를 명시하면 이해하기 쉽다.

## 3. 레지스터 보존과 배열 합계

프로시저 안에서 호출자의 레지스터를 바꿀 경우, 필요한 값을 `PUSH`로 저장하고 돌아가기 전 **역순으로 `POP`**한다. 다만 **EAX를 반환값으로 쓰면서 복원하면 계산 결과가 사라진다.** MASM의 `USES esi ecx`는 해당 레지스터의 저장·복구 코드를 만들어 준다.

수업 자료의 `ArraySum`은 **ESI=배열 시작 주소, ECX=원소 수**를 받아 각 DWORD를 더하고 **EAX=합계**로 반환한다. 핵심 흐름은 다음과 같다.

```asm
mov eax, 0
L1:
    add eax, [esi]         ; 현재 DWORD 더하기
    add esi, TYPE DWORD    ; 다음 원소(4바이트)로
    loop L1               ; ECX를 줄이고 반복
```

## 4. 라이브러리와 Irvine32

**링크 라이브러리**에는 미리 작성된 프로시저가 들어 있다. Windows의 `kernel32.lib`는 `kernel32.dll`의 함수를 연결하는 데 쓰이며, 수업의 **Irvine32**는 입출력을 쉽게 해 주는 학습용 라이브러리다.

| 프로시저 | 역할 |
|---|---|
| `ReadInt` | 키보드에서 부호 있는 정수를 읽어 EAX에 저장 |
| `WriteInt` / `WriteDec` | EAX의 값을 부호 있는/없는 10진수로 출력 |
| `WriteString` | EDX가 가리키는 널 종료 문자열 출력 |
| `Crlf` / `Clrscr` | 줄바꿈 / 화면 지우기 |
| `DumpRegs` / `DumpMem` | 레지스터 / 메모리 확인 |

예: `mov edx, OFFSET msg` → `call WriteString`. 정수를 입력할 때는 `call ReadInt` 후 **EAX**를 사용한다.
