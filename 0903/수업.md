# 어셈블리 프로그래밍 1장 — Basic Concepts

> 원본: `1. Basic Concepts-1.pdf` (26쪽)  
> 핵심: 어셈블리 언어의 위치 → 데이터 표현 → 불 연산

## 1. 어셈블리 언어란?

- **기계어**는 CPU가 직접 실행하는 0과 1의 명령이다.
- **어셈블리 언어**는 기계어 명령을 사람이 읽기 쉬운 기호로 표현한다. 예를 들어 `MOV AL, 97`은 97을 AL 레지스터에 넣는 명령이다.
- **고급 언어**(C++, Java 등)는 하드웨어의 세부 명령보다 프로그램의 기능을 표현하기 쉽다.
- **어셈블러**는 어셈블리 코드를 기계어가 담긴 목적 파일로 바꾸고, **링커**는 목적 파일과 필요한 코드를 연결해 실행 파일을 만든다. 수업 자료에는 MASM, MASM32, NASM, GAS 등의 어셈블러가 소개된다.
- 어셈블리 코드는 CPU의 명령어 집합에 의존한다. 따라서 한 CPU용 코드를 다른 종류의 CPU에서 그대로 실행하기는 어렵다.

## 2. 가상 머신과 명령어 계층

상위 언어의 명령은 결국 하위 단계에서 실행 가능한 형태로 바뀐다. 수업 자료의 계층 그림은 **고급 언어 → 어셈블리 언어 → 명령어 집합(기계어) → 디지털 논리/하드웨어**의 관계를 보여준다. 여기서 *가상 머신*은 다른 컴퓨터의 기능을 소프트웨어로 흉내 내는 개념이다.

## 3. 진법과 데이터 크기

| 진법 | 밑 | 쓰는 숫자 |
|---|---:|---|
| 2진수 | 2 | 0, 1 |
| 8진수 | 8 | 0~7 |
| 10진수 | 10 | 0~9 |
| 16진수 | 16 | 0~9, A~F (A=10, F=15) |

- **MSB**는 가장 왼쪽의 높은 자리 비트, **LSB**는 가장 오른쪽의 낮은 자리 비트다.
- 2진수 덧셈에서 `1 + 1 = 10₂`: 0을 쓰고 다음 자리로 1을 올린다. 예: `0100₂ + 0111₂ = 1011₂` (4 + 7 = 11).
- 2진수 **4자리 = 16진수 1자리**다. 예: `1010 1111₂ = AF₁₆`.
- 16진수 덧셈도 한 자리의 합이 16 이상이면 올림한다. 예: `6A2₁₆ + 49A₁₆ = B3C₁₆`.

| 이름 | 크기 |
|---|---:|
| Byte | 8비트 |
| Word | 16비트 |
| Doubleword | 32비트 |
| Quadword | 64비트 |
| Double quadword | 128비트 |

## 4. 음수 표현: 2의 보수

맨 왼쪽 비트를 **부호 비트**로 보며, 고정된 비트 수에서 음수는 **비트 반전 후 1 더하기**로 표현한다.

```text
+1 = 0000 0001
반전  1111 1110
+1   1111 1111  → 8비트의 -1
```

반대로 음수의 크기를 구할 때도 비트를 반전하고 1을 더하면 된다. `1111 0000₂` → 반전 `0000 1111₂` → `0001 0000₂`(16)이므로 **8비트 부호 있는 값으로 -16**이다.

- n비트 **부호 있는 정수** 범위: `-2^(n-1)` ~ `2^(n-1)-1`.
- 예: 8비트 부호 있는 정수는 **-128~127**, 16비트는 **-32768~32767**.
- 뺄셈은 해당 비트 수에서 상대 수의 2의 보수를 더하는 방식으로 계산할 수 있다. 예: `13 - 7 = 13 + (-7) = 6`.

## 5. 문자의 저장 방식

| 방식 | 요점 |
|---|---|
| ASCII | 7비트 코드, 0~127. 영문자·숫자·기호 등을 표현 |
| 확장 ASCII | 8비트, 0~255. 추가 문자와 기호를 포함하나 코드 페이지에 따라 내용이 달라짐 |
| Unicode | 여러 언어의 글자와 기호를 공통으로 다루는 체계. UTF-8·UTF-16·UTF-32 등으로 인코딩 |

**UTF-8**은 문자에 따라 1~4바이트(ASCII 문자는 1바이트), **UTF-16**은 2~4바이트, **UTF-32**는 4바이트를 사용한다. Unicode의 문자 번호와 실제 저장에 쓰는 인코딩은 구분해서 기억한다.

## 6. 불 연산(Boolean expressions)

| 연산 | 의미 | 예시 (`X=참`, `Y=거짓`) |
|---|---|---|
| `¬X` (NOT) | 참/거짓 뒤집기 | 거짓 |
| `X ∧ Y` (AND) | 둘 다 참일 때 참 | 거짓 |
| `X ∨ Y` (OR) | 하나라도 참이면 참 | 참 |

`¬X ∨ Y`처럼 여러 연산이 있으면 **NOT → AND → OR** 순서로 계산한다. 괄호가 있으면 괄호 안부터 계산한다.
