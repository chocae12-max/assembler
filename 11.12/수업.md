# 9장. Strings and Arrays

## 1. 문자열 명령어

32비트 문자열 명령어는 주로 `ESI`(원본 주소), `EDI`(대상 주소), `ECX`(반복 횟수), `AL/AX/EAX`(비교·저장할 값)를 암묵적으로 쓴다. 끝의 `B/W/D`는 각각 1/2/4바이트 단위를 뜻한다.

| 명령어 | 하는 일 |
| --- | --- |
| `MOVSB/W/D` | `[ESI]`에서 `[EDI]`로 복사 |
| `CMPSB/W/D` | `[ESI]`와 `[EDI]`를 비교 |
| `SCASB/W/D` | `AL/AX/EAX`와 `[EDI]`를 비교 |
| `STOSB/W/D` | `AL/AX/EAX`를 `[EDI]`에 저장 |
| `LODSB/W/D` | `[ESI]` 값을 `AL/AX/EAX`로 읽음 |

`CLD`는 주소가 증가하는 방향, `STD`는 감소하는 방향으로 설정한다. `REP`는 `ECX`회 반복하고, `REPE`는 같을 동안(`ZF=1`), `REPNE`는 다를 동안(`ZF=0`) 반복한다. 비교용 반복도 `ECX=0`이면 멈춘다.

`CMPSB`는 두 메모리의 바이트를 비교하면서 `ESI`와 `EDI`를 이동한다. `SCASB`는 `AL`에 넣은 문자를 대상 문자열에서 찾을 때 쓰기 좋다. `STOSB`는 같은 문자를 연속으로 채우는 데 쓸 수 있다. 어느 방향으로 움직일지는 방향 플래그(`DF`)가 결정한다.

```asm
cld
mov esi, OFFSET source
mov edi, OFFSET target
mov ecx, LENGTHOF source
rep movsb
```

위 코드는 `source`의 바이트를 `target`으로 복사한다. 대상 배열은 충분한 크기로 준비해야 한다.

## 2. Irvine32 문자열 프로시저

| 프로시저 | 용도 |
| --- | --- |
| `Str_length` | 문자열 길이를 `EAX`로 반환 |
| `Str_compare` | 두 문자열 비교, 같으면 `ZF=1` |
| `Str_copy` | 문자열 복사 |
| `Str_trim` | 문자열 **뒤쪽**의 지정 문자를 제거 |
| `Str_ucase` | 영문 소문자를 대문자로 변경 |

문자열 비교는 대소문자를 구별한다. 복사할 때는 종료용 널 문자까지 들어갈 공간이 필요하다.

Irvine32 프로시저를 쓸 때는 필요한 주소와 값을 약속된 레지스터에 넣어 호출한다. `Str_compare`는 같으면 `ZF=1`이고 첫 문자열이 사전순으로 앞서면 `CF=1`이다. `Str_trim`은 문자열 중간의 문자를 지우는 기능이 아니다.

## 3. 2차원 배열 주소와 검색

행 우선 배열의 주소는 `시작 주소 + (행 번호 × 열 개수 + 열 번호) × 원소 크기`다. 예를 들어 4열짜리 `DWORD` 배열에서 `[2][1]`의 시작점 기준 이동량은 `(2×4+1)×4=36`바이트다. x86 주소 계산에는 `기준 레지스터 + 인덱스 레지스터×배율 + 상수` 형태를 쓸 수 있으며 배율은 1·2·4·8이다.

- **버블 정렬:** 이웃한 두 원소를 비교해 순서가 다르면 교환한다. 한 번 끝까지 돌면 가장 큰 값이 뒤쪽에 자리 잡는다.
- **이진 검색:** **정렬된 배열**에서 가운데 원소와 비교해 검색 범위를 절반으로 줄인다. 자료의 정렬 여부가 핵심 조건이다.

버블 정렬은 배열 전체를 여러 차례 순회하므로 원소가 많으면 느리다. 이진 검색은 찾은 위치를 인덱스로 반환하고, 없으면 `-1`을 반환하도록 구현할 수 있다.

**빠르게 확인하기:** `ESI`/`EDI`의 역할, `CLD`/`STD`, `REP` 계열의 종료 조건, 2차원 배열의 바이트 오프셋을 연습하자.
