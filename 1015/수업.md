# 어셈블리 프로그래밍 6장 — Conditional Processing

> 원본: `6. Conditional Processing-1.pdf` (70쪽)

## 1. 비트 연산과 조건 확인

| 명령 | 동작 | 쓰임 |
|---|---|---|
| `AND` | 둘 다 1인 비트만 1 | 마스크로 특정 비트 남기기/지우기 |
| `OR` | 하나라도 1이면 1 | 특정 비트 켜기 |
| `XOR` | 두 비트가 다르면 1 | 비트 뒤집기, 같은 키로 다시 XOR하면 복원 |
| `NOT` | 모든 비트 반전 | 1의 보수 |
| `TEST a, b` | `a AND b`의 결과로 플래그만 설정 | 값을 바꾸지 않고 비트 검사 |
| `CMP a, b` | `a - b`의 결과로 플래그만 설정 | 두 값의 크기·같음 비교 |

`AND`·`OR`·`XOR`·`TEST`는 **CF와 OF를 0으로** 하고 ZF·SF·PF를 갱신한다. `NOT`은 플래그를 바꾸지 않는다. `CMP`는 피연산자를 바꾸지 않고 뺄셈 결과에 맞게 플래그를 갱신한다.

**자주 볼 플래그:** `ZF=1`(결과 0), `CF=1`(부호 없는 뺄셈에서 빌림), `SF`(부호), `OF`(부호 있는 연산의 범위 초과).

## 2. CMP 다음의 조건 점프

```asm
cmp eax, ebx
je  same        ; EAX = EBX이면 이동
jg  greater     ; 부호 있는 값으로 EAX > EBX
jmp other       ; 무조건 이동
```

| 비교 | 같음/다름 | 더 큼 | 더 작음 | 크거나 같음 | 작거나 같음 |
|---|---|---|---|---|---|
| **부호 있는 정수** | `JE` / `JNE` | `JG` | `JL` | `JGE` | `JLE` |
| **부호 없는 정수** | `JE` / `JNE` | `JA` | `JB` | `JAE` | `JBE` |

`JZ`는 **ZF=1**, `JNZ`는 **ZF=0**일 때 이동한다. `JC`/`JNC`는 CF를 검사한다. **부호 있는 비교(`JG`, `JL`)와 부호 없는 비교(`JA`, `JB`)는 섞지 않는다.** 예를 들어 `cmp eax, 0` 뒤 `jz zero`는 EAX가 0일 때만 이동한다.

## 3. 반복문과 조건문 만들기

고급 언어의 `if`·`while`은 **비교 → 조건 점프 → 레이블**로 만든다.

```asm
L1:
    cmp eax, ebx
    jge done          ; EAX >= EBX이면 끝
    inc eax
    jmp L1
done:
```

`LOOP`는 ECX를 1 줄인 뒤 0이 아니면 분기한다. `LOOPE`/`LOOPZ`는 **ECX≠0이면서 ZF=1**, `LOOPNE`/`LOOPNZ`는 **ECX≠0이면서 ZF=0**일 때 계속한다. 반복 도중 비교 플래그를 유지해야 하면 플래그를 바꾸는 명령에 주의한다.

## 4. 수업 자료의 응용

- 배열에서 처음 나오는 0이 아닌 값을 찾을 때: 원소를 `CMP`로 비교하고 `JNZ`로 찾은 위치로 이동한다.
- 문자열의 각 바이트를 같은 키와 **XOR 두 번** 하면 원래 문자로 복원된다. 예제는 이 성질로 암호화·복호화를 보여준다.
- **테이블 기반 선택**은 입력 값과 표의 값을 비교해 해당 프로시저 주소를 호출한다.
- **32비트 MASM**에서는 `.IF` / `.ELSE` / `.ENDIF`, `.WHILE` / `.ENDW`, `.REPEAT` / `.UNTIL` 같은 지시어로 조건·반복을 간단히 쓸 수 있다. 자료에서는 이 고급 지시어를 64비트 모드에 쓸 수 없다고 설명한다.

## 빠르게 확인하기

1. 값을 바꾸지 않고 AND 결과의 플래그만 확인하는 명령은? → **TEST**
2. 부호 없는 `EAX > EBX` 분기는? → **CMP 후 JA**
3. `JZ`는 어떤 때 이동하나? → **ZF=1일 때**
