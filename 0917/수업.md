# 어셈블리 프로그래밍 3장 — Assembly Language Fundamentals

> 원본: `3. Assembly Language Fundamentals.pdf` (50쪽)

## 1. 명령어의 기본 형태

```asm
[레이블:] 명령어 [피연산자] [; 주석]
mov eax, 5       ; EAX에 5 저장
add eax, 6       ; EAX = 11
```

- **니모닉**은 `MOV`, `ADD`, `SUB`, `JMP`, `CALL` 같은 명령 이름이다.
- **피연산자**는 계산에 쓰이는 값이다. `mov count, eax`에서는 왼쪽 `count`가 목적지, 오른쪽 `eax`가 원본이다.
- **레이블**은 데이터나 코드의 위치에 붙인 이름이다. `target:`처럼 분기 목적지로 쓸 수 있다.
- **지시어**는 실행 명령이 아니라 어셈블러에 내리는 지시다. 예: `.data`, `.code`, `BYTE`, `DWORD`.
- `;` 뒤는 해당 줄의 주석이다. `NOP`은 아무 계산도 하지 않는 명령이다.

## 2. 상수와 프로그램 구조

정수 상수는 `26`(10진수), `1101b`(2진수), `1Ah`(16진수)처럼 쓴다. 16진수가 문자 A~F로 시작할 때는 `0A3h`처럼 앞에 0을 붙인다. 정수식에서는 괄호와 곱셈·나눗셈이 덧셈·뺄셈보다 우선한다.

```asm
.data
sum DWORD 0          ; 32비트 변수
.code
main PROC
    mov eax, 5
    add eax, 6
    mov sum, eax
    INVOKE ExitProcess, 0
main ENDP
END main
```

`.data`에는 변수, `.code`에는 실행 명령을 둔다. `PROC`와 `ENDP`는 프로시저의 시작과 끝을 나타낸다. 작성한 소스(`.asm`)는 **어셈블 → 목적 파일(`.obj`) → 링크 → 실행 파일(`.exe`)** 순서로 처리된다.

## 3. 데이터 정의하기

| 지시어 | 저장 크기 | 예 |
|---|---:|---|
| `BYTE` / `SBYTE` | 8비트 | `age BYTE 20` |
| `WORD` / `SWORD` | 16비트 | `score WORD 1000` |
| `DWORD` / `SDWORD` | 32비트 | `sum DWORD ?` |
| `QWORD` | 64비트 | `big QWORD 100` |
| `REAL4` / `REAL8` | 4 / 8바이트 실수 | `rate REAL4 1.5` |

이름에 `S`가 붙으면 부호 있는 정수를 뜻한다. `?`는 초기값을 지정하지 않았다는 뜻이다.

```asm
nums BYTE 10, 20, 30       ; 연속된 3개 값
zeros BYTE 5 DUP(0)        ; 0으로 채운 5바이트
text BYTE "Hello", 0       ; 끝에 널(0)이 있는 문자열
```

배열의 이름은 **첫 번째 값의 주소**를 가리킨다. `.DATA?`에는 초기화하지 않은 큰 데이터를 둘 수 있다. x86의 **리틀 엔디언** 방식에서는 `12345678h`를 메모리에 낮은 주소부터 `78h 56h 34h 12h` 순서로 저장한다.

## 4. 기호 상수

`COUNT = 5`처럼 `=`로 정수 상수를 정하고, `PI EQU <3.1416>`처럼 `EQU`로 이름에 값·텍스트를 연결한다. `TEXTEQU`는 텍스트를 치환하는 매크로다. 배열 길이를 구할 때는 현재 위치를 나타내는 `$`를 이용할 수 있다.

```asm
items BYTE 10, 20, 30
itemCount = ($ - items)    ; 3바이트 → BYTE 원소 3개
```

## 빠르게 확인하기

1. `mov eax, 5`의 목적지는? → **EAX**
2. `DWORD`와 `?`의 의미는? → **32비트 공간, 초기값 미지정**
3. `BYTE 4 DUP(0)`은? → **0인 바이트 4개**
